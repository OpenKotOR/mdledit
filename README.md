# MDLedit (archived source mirror)

MDLedit is a compiler and decompiler for the binary and ASCII model formats of
Star Wars: Knights of the Old Republic and Knights of the Old Republic II. It was
written by **bead-v**. All code in this repository is their work.

## Archive notice

This repository is a read-only archive and does not accept issues or pull
requests. It preserves the source bead-v published at
<https://bitbucket.org/bead-v/mdledit>, with the same commit history.

**For released builds, use Deadlystream:**
<https://deadlystream.com/files/file/1150-mdledit/>

The source here is not the released v1.0.3 build. The version string in
`frame.cpp` shows that the history covers:

| Version           | First commit | Notes                                            |
|-------------------|--------------|--------------------------------------------------|
| v0.4.10           | 2017-09-06   | Pre-release development                          |
| v1.0.3            | 2018-02-16   | Same version as the Deadlystream release         |
| v1.0.4            | 2018-04-30   | Never released                                   |
| v1.1.0 (`master`) | 2018-08-17   | Never released. Some features are unfinished     |

No commit carries a version between v0.4.10 and v1.0.3.

## Original README

### What is this repository for? ###

This repository contains the source code for mdledit.

### How do I get set up? ###

Statically linked: gdi32, user32, kernel32, comctl32, comdlg32, Shlwapi, winmm.

C++14 is used.

### Who do I talk to? ###

PM me on deadlystream.com (bead-v).
